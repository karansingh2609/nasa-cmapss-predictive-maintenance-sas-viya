# Project Screenshots

This folder contains screenshots documenting the development and
evaluation of the NASA C-MAPSS predictive maintenance project
using SAS Viya and SAS Model Studio.

## Contents

The screenshots document:

1. Dataset and variable structure
2. Data preparation
3. Feature engineering
4. Model development
5. Model comparison
6. Model evaluation
7. SAS Model Manager
8. Model health and influential variables

These screenshots provide visual evidence of the workflow
described in the project documentation.
